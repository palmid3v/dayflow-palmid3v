# DayFlow — PALMI-D3V

**Plan → Do → Track → Remember**

DayFlow is a mobile-first personal routine system that combines scheduled calendar blocks, reminders, tasks, daily tracking, and written daily memories.

## Current MVP
- 📅 Daily timeline
- ✅ Unified task surface
- 📊 Daily progress indicator
- 📝 Daily Memory concept
- 📱 Mobile-first responsive UI
- 🎨 Dark personal-dashboard visual language
- ✨ Emoji-driven activity categories
- 🔗 Architecture reserved for future To-Do integration

## Iconography
DayFlow uses [Lucide](https://lucide.dev/) for interface icons. Lucide provides lightweight, scalable SVG icons with customizable styling and tree-shaking support.

## Product loop
**Calendar + Reminders + To-Do → Daily Plan → Track Result → Written Memory**

## Development
```bash
npm install
npm run dev
npm run build
```
